First launch

From APK to first join in 4 steps.

Keep the host phone connected to Wi-Fi and power while the server runs. The interactive setup wizard in the dashboard guides you through every step.

  1. 01Android 8+

    Install MineHost

    Download the single APK on an ARM64 Android phone. Open it and tap Start setup—no Termux or terminal commands needed.

  2. 02Encrypted Link

    Pair your phone

    Create a MineHost account or sign in. Confirm the one-time device pairing in your browser and return to the app.

  3. 03Mojang Official

    Choose your engine

    Pick Paper, Fabric, Vanilla, or Pumpkin. Read and accept the Minecraft EULA, then configure RAM, gamemode, and whitelist.

  4. 04LAN & Internet

    Start & invite friends

    Start the server and join via the local Wi-Fi address—or follow the built-in router guide under Network for external players.

Help & architecture

Good to know.

The Help tab inside your dashboard can reopen the complete interactive setup guide at any time.

How do friends connect from another network?

First test the local address on the same Wi-Fi. Under Network in the dashboard, follow your router's port forwarding steps. Give friends the public address and external port, then test from a different network.

Can Java and Bedrock players share a world?

MineHost 0.10.14 offers experimental crossplay on Pumpkin for Java 26.3 and Bedrock 26.60. Enable Allow Bedrock players and restart. The dashboard shows the separate Bedrock port for TCP and UDP. This mode runs without plugins or PatchBukkit. Paper crossplay is currently unavailable on Android.

Where are my world files and is my server secure?

Worlds and backups never leave your host phone unless you download them. Online authentication (online-mode=true) is enforced, device tokens are uniquely generated during pairing, and co-admin invitations can be restricted or revoked at any moment.

Why does my phone appear offline?

Check the phone's Wi-Fi connection, open MineHost and tap Open website. Sign in with the account linked to the phone. To prevent Android from putting the server to sleep, set MineHost's battery usage to unrestricted.

How do I update MineHost without losing my world?

Stop your server cleanly in the app or dashboard so it saves the world, then install the new APK over your existing MineHost app. All profiles, worlds, and backups are preserved.
