Dein Minecraft-Server
auf deinem Handy

Hoste Minecraft Java auf Android. Starte und stoppe den Server in der App. Verwalte Welten, Erweiterungen und Backups im Browser.

Neueste APK herunterladen

So richtest du deinen Server ein

  1. Installiere die APK auf einem ARM64-Android-Handy und öffne MineHost.
  2. Tippe auf Einrichtung starten. Erstelle ein Konto und verknüpfe das Handy im Browser.
  3. Wähle Minecraft-Version und Serversoftware. Lies die EULA und bestätige sie, wenn du zustimmst.
  4. Starte den Server. Teste den Beitritt in Minecraft Java über die im Dashboard angezeigte WLAN-Adresse.
  5. Für Freunde außerhalb des WLANs öffne Hilfe im Dashboard und folge dem Router-Tutorial. Teile die öffentliche Adresse mit dem externen Port.

Serversoftware und Erweiterungen

Paper unterstützt kompatible Plugins. Fabric unterstützt passende Mods und installiert die Fabric API automatisch. Du kannst auch Vanilla oder Pumpkin wählen. PatchBukkit ist noch nicht enthalten.

Profile speichern Welten und Einstellungen getrennt. Auf dem Handy läuft jeweils ein Server.

Hilfe und Updates

Handy offline? Prüfe Internet und öffne MineHost. Tippe auf Website öffnen und melde dich mit dem verknüpften Konto an.

Freunde können nicht beitreten? Prüfe die Minecraft-Version, die Whitelist und die TCP-Portfreigabe zum Handy. Teste die öffentliche Adresse aus einem zweiten Netzwerk.

Update installieren? Stoppe den Server, lade die neueste APK und installiere sie über die vorhandene App.
