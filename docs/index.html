Your Minecraft server
on your phone

Host Minecraft Java on Android. Control the server from the app, and manage worlds, add-ons, and backups from your browser.

Download the latest APK

Set up your server

  1. Install the APK on an ARM64 phone running Android 8 or later.
  2. Open MineHost and tap Start setup. Create a MineHost account and link the phone.
  3. Choose a Minecraft version and server engine. Read and accept the Minecraft EULA to install it.
  4. Start the server and join from Minecraft Java using the local address shown in the dashboard.
  5. For friends outside your Wi-Fi network, follow the router guide under Help and share the public address and external port.

Server engines and add-ons

Use Paper for compatible plugins or Fabric for mods. MineHost installs Fabric API automatically. Vanilla and Pumpkin are also available. The current release does not include PatchBukkit.

Profiles keep worlds and settings separate. One server runs at a time.

Help and updates

Phone offline? Check its internet connection, open MineHost, and tap Open website. Sign in with the linked account.

Friends cannot join? Check their Minecraft version, the allowlist, and the TCP port forwarding rule. Test the public address from a second network.

Updating? Stop the server so it saves your world, then install the latest APK over the existing app.
