# MineHost

Betreibe einen Minecraft-Java-Server auf deinem Android-Handy. MineHost bringt die Java-Laufzeit mit. Auf dem Handy steuerst du den Server und siehst seinen Ressourcenverbrauch. Im Browser verwaltest du Einstellungen, Dateien, Erweiterungen und Backups.

[Neueste APK herunterladen](https://github.com/adrighg-scripts/MineHost/releases/latest/download/MineHost.apk) · [Einrichtung und Hilfe](https://adrighg-scripts.github.io/MineHost/) · [Alle Versionen](https://github.com/adrighg-scripts/MineHost/releases)

## Schnellstart

1. Installiere die APK auf einem Android-Handy mit ARM64. Erlaube deinem Browser bei Bedarf, die APK zu installieren.
2. Öffne MineHost und tippe auf **Einrichtung starten**. Erstelle auf der Website ein MineHost-Konto und verknüpfe das Handy.
3. Wähle die Serversoftware und Minecraft-Version. Lies die Minecraft-EULA und bestätige sie, wenn du zustimmst.
4. Starte den Server auf der Website oder in der App. Verbinde dich in Minecraft Java zuerst über die WLAN-Adresse.
5. Für Freunde außerhalb des WLANs folge dem Router-Tutorial im Dashboard. Teile anschließend die öffentliche Adresse mit dem externen Port.

## Serversoftware

- **Paper** für Bukkit- und Paper-Plugins.
- **Fabric** für kompatible Server-Mods. MineHost installiert die passende Fabric API automatisch.
- **Vanilla** für den originalen Minecraft-Server.
- **Pumpkin** als alternative Serversoftware. PatchBukkit ist in dieser Version noch nicht enthalten.

Mehrere Profile speichern ihre Welten und Einstellungen getrennt. Pro Handy läuft jeweils ein Server. Änderungen an Dateien, die du während des Spielbetriebs hochlädst oder löschst, werden nach dem Stopp angewendet.

## Updates und Quellcode

Lade die neueste APK aus den Releases und installiere sie als Update über die vorhandene App. Stoppe den Server vorher, damit die Welt gespeichert wird. Die Releases enthalten auch das Android-Projekt und den Quellcode der mitgelieferten Laufzeiten.
