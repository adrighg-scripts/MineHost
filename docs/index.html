First launch

From APK to first join.

Keep the host phone connected to Wi-Fi and power while the server runs. The dashboard setup guide walks you through the rest.

  1. 01

    Install MineHost

    Download the APK on an ARM64 Android 8+ phone. Open it and tap Start setup.

  2. 02

    Link your phone

    Create a MineHost account or sign in with an existing one. Confirm the device and return to the app.

  3. 03

    Choose your server

    Pick the Minecraft version and engine. Read and accept the Minecraft EULA before installing. Set the game mode, player limit and allowlist.

  4. 04

    Start and join

    Start the server, wait for the dashboard to show it is running and join with the local address. Follow Network to invite friends from outside your Wi-Fi.

Server engines

Pick how you play.

Choose an engine when you set up a server. Each server has its own world and settings. One server can run at a time on each phone.

P

Paper

Run compatible Bukkit and Paper plugins. Good for commands, permissions and server-side tools.

Java · plugins
F

Fabric

Use compatible mods. MineHost installs Fabric API automatically. Some mods also need to be installed by each player.

Java · mods
V

Vanilla

Run the official Minecraft server for a familiar survival or creative world.

Java · classic
P

Pumpkin

Try native Pumpkin plugins or compatible Bukkit plugins through PatchBukkit. Experimental Bedrock crossplay uses Pumpkin without plugins.

Java · experimental crossplay

Help & updates

Good to know.

The Help tab in your dashboard can reopen the complete setup guide at any time.

How do friends connect from another network?

First test the local address on the same Wi-Fi. Under Network in the dashboard, follow your router's port forwarding steps. Give friends the public address and port, then test from a different network.

Can Java and Bedrock players share a world?

MineHost 0.10.14 offers experimental crossplay on Pumpkin for Java 26.3 and Bedrock 26.60. Enable Allow Bedrock players and restart. The dashboard shows the separate Bedrock port for TCP and UDP. This mode runs without plugins or PatchBukkit. Paper crossplay is currently unavailable on Android.

Why does my phone appear offline?

Check the phone's internet connection, open MineHost and use Open website. Sign in with the account linked to the phone. If Android stops the app in the background, check MineHost's battery settings.

How do I update MineHost?

Stop your server so it saves the world. Install the latest APK over the existing MineHost app. Previous versions, release notes and source downloads are available on GitHub.

Where are my world files?

Worlds and backups are stored on the host phone. Use the dashboard to browse the files and export backups to another device.
