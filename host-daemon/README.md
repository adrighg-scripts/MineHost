# MineHost — Cross-Platform Server Host (Windows & Linux / Ubuntu)

Verwandelt deinen Windows-PC oder Linux/Ubuntu-Server mit 1 Klick in einen vollständigen Minecraft-Server-Host inklusive lokalem Web-Panel (`http://localhost:8787`) und Live-Synchronisation mit dem Online-Dashboard (`https://minehost-dashboard.adrilolghg.workers.dev`).

## Schnellstart

### Windows 10 / 11
1. Entpacke `MineHost_Windows.zip` in einen beliebigen Ordner.
2. Doppelklicke auf **`Start-MineHost-Windows.bat`**.
3. Falls Node.js oder Java noch nicht installiert sind, lädt MineHost diese vollautomatisch und portabel herunter (keine manuelle Installation nötig).
4. Dein Browser öffnet automatisch das Dashboard zur 1-Klick-Verknüpfung.

### Linux / Ubuntu / Debian
1. Entpacke `MineHost_Linux.zip`:
   ```bash
   unzip MineHost_Linux.zip -d MineHost
   cd MineHost
   chmod +x start-minehost-linux.sh
   ./start-minehost-linux.sh
   ```
2. Öffne den im Terminal angezeigten Pairing-Link im Browser oder steuere den Server lokal über `http://localhost:8787`.

### iOS (iPhone & iPad)
1. Öffne `https://minehost-dashboard.adrilolghg.workers.dev` in Safari.
2. Tippe auf **Teilen → Zum Home-Bildschirm**, um MineHost als Vollbild-App auf iOS zu nutzen und deinen Server von überall zu steuern.
